# 大学物理交互模型

Whether you just want to finish your homework or deepen your study, use my college physics interactive simulation. Here we will learn from the basics of electromagnetism and so on. You can record every parameter for interaction, and transform the incomprehensible knowledge in books into visual simulation. This process is both easy and interesting.

当前已上传 **电磁学 [1]** 网页端交互模型，包含库仑力、电场与电势、平行板电容器、高斯定律、带电粒子运动和 RC 充放电。模型说明、运行方法与物理边界见 [电磁学 [1] 项目说明](electromagnetism-1/README.md)。

电磁学 [2]、光学和近代物理学项目包会在内容完成后再上传。
