# 电磁学 [1]：电场与电路基础

已完成的网页端交互模型：

1. **库仑力**：拖动两个点电荷，改变电荷量，观察距离、方向与受力的关系。
2. **电场与电势**：摆放多个点电荷，查看电场矢量、等势线，以及探针位置的电场强度与电势。
3. **平行板电容器**：调整电压、极板间距、极板面积及相对介电常数，观察电容、电荷量、电场和储能。
4. **高斯定律**：切换均匀带电实心球、无限长均匀带电薄圆柱面和孤立无限大均匀带电平面，比较不同高斯面的包围电荷、电通量与电场。
5. **带电粒子运动**：电子或质子水平射入匀强电场，查看偏转轨迹、出射或撞板结果。
6. **RC 充放电**：切换充电与放电，观察电容电压、电荷量、电流和时间常数。

运行：

```powershell
cd '电磁学[1]'
npm start
```

然后打开 `http://localhost:4173`。运行公式检查：

```powershell
npm test
```

## 物理模型与边界

- 点电荷采用真空中的库仑定律和线性叠加，坐标单位为米，电荷单位为库仑。两个电荷重合或探针进入电荷标记附近时，结果标记为未定义。
- 等势线为有限网格上的数值绘制结果，用于观察趋势；电荷附近的线条和画布边缘可能不连续。
- 电容器采用完全填充均匀电介质的理想平行板模型，忽略边缘效应和击穿；板间电场取 `E = V / d`。
- 高斯定律模型采用球对称、体电荷密度均匀的绝缘实心球。球内 `Q内 = Q(r/R)³`，球外 `Q内 = Q`；画布中的圆仅为球的截面。
- 圆柱面模型采用无限长、表面电荷密度均匀的理想薄圆柱壳。壳内 `E = 0`；壳外 `E = σR/(ε₀r)`，长度为 `L` 的同轴高斯柱包围 `Q内 = σ2πRL`。在 `r = R` 且带电时，理想面两侧电场跳变，读数标记为未定义；横截面和轴向侧视图随参数同步更新，侧视图中的高斯柱端盖电通量为零。
- 平面模型采用孤立、无限大、均匀带电的理想平面，忽略边缘效应。两侧场强大小均为 `|σ|/(2ε₀)`、方向相反；跨越平面的高斯柱盒包围 `Q内 = σA`，总通量为 `σA/ε₀`。柱盒半高不影响结果；平面自身位置的电场不定义。
- 粒子运动模型采用均匀板间电场，忽略边缘效应、重力、粒子相互作用与相对论效应；板长为 12 cm。
- RC 模型采用理想串联电路；充电时初始电容电压为零，放电时为 `U₀`，放电电流以充电方向为正，因此显示负号。

后续模型及“电磁学 [1]”与“电磁学 [2]”的边界，由后续具体需求确定。
